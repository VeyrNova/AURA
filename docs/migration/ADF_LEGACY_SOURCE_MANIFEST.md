# Recovered ADF legacy source manifest

Both authorised sources contain matching SHA-256 contracts for ADF-A through ADF-H: manifests, policies, capability charter, developer-mode policy, roadmap, coding-agent catalog, provider registry/source/free-tier snapshots, IDE bridges and terminal integrations.

Executable historical references include `aura_dev_fabric.py`, `runtime/aura_developer_fabric.py`, `runtime/aura_fabric_provider_registry.py` and the `agent/` package. They depend on the historical runtime and are not copied blindly. The old UI is Chromium and remains reference-only.

Credentials, `.env`, audit/transaction ledgers, backups, tokens, provider key material, generated bundles and local state are explicitly excluded.
