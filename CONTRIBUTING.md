# Contributing

Please open an issue before proposing a substantial change. Keep changes scoped, preserve local-first behavior, and add focused regression tests for runtime, QML bridge, provider, persistence, or lifecycle changes.

Do not include credentials, OAuth material, user databases, logs, caches, generated evidence, or files from `C:\AURA GPT version` in a change. Run the relevant focused tests before submitting a pull request.
